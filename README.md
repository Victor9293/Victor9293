#### Featured project

**[LLM Evaluation Benchmark](https://github.com/Victor9293/llm-evaluation-benchmark)** · [open the live app →](https://victor9293.github.io/llm-evaluation-benchmark/)

A browser-based workbench to benchmark and human-evaluate LLM responses:

- 56 test cases (16 in European Portuguese) covering factual accuracy, hallucination resistance, instruction following and reasoning
- 73 automated checks, plus a five-criterion human rubric
- no API keys, and it ships with no results: every evaluation is entered by hand

It's a small, early-stage personal project, built with AI coding assistance.
